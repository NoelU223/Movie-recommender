# Movie Recommender

Backend dio sustava za preporuku filmova.
Projekt je dio kolegija Infrastruktura podataka velikog obujma (IPVO).

Faza 1: Backend servis + baza podataka + skalabilnost.
Baza se pokreće s docker compose up --build i onda se testira na http://localhost/docs
Frontend za prvu fazu odrađuje kolega na projektu.
